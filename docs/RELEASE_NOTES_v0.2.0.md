# MoonJMES v0.2.0

MoonJMES v0.2.0 turns the initial query core into a reusable MoonBit JSON-query
toolkit and browser-demonstrable ecosystem library.

Highlights:

- 908 attributed upstream compliance cases with zero expected failures;
- opaque compiled APIs and formal compile-time contracts;
- cached/extensible engine, custom functions, batch isolation, and metrics;
- diagnostics, AST export, static analysis, plans, and bounded traces;
- NDJSON transforms, multi-stage pipelines, and named query catalogs;
- visual Playground built from the same MoonBit library;
- 3,500+ lines of production MoonBit source, four-backend verification,
  coverage reporting, benchmarks, JS/browser checks, and reproducible assets.

See `docs/RELEASE_EVIDENCE.md` for the Issue → PR → Actions traceability matrix.
